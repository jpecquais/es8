Tools for the ES-8

Free, open-source tools for the BOSS ES-8 Effects Switching System. They read your patches over MIDI, let you change them, and check every write by reading it back.

Web editor

ES8 Control

Edit patches, footswitches, assigns and system settings. Reorder the loop chain, swap or move patches, change many patches at once. Runs in your browser; nothing to install.

Command line

es8ctl

Scriptable, JSON output, made for automation and AI agents.

uv tool install es8ctl
es8ctl names -p WIDI

Or in Docker (no MIDI on macOS; on Linux, pass --device /dev/snd):

docker run --rm ghcr.io/<owner>/es8-cli --help

What you need

  • A BOSS ES-8 with firmware 2.x.
  • A MIDI link in both directions: a USB MIDI interface with two cables, or a Bluetooth adapter such as a CME WIDI Jack.
  • Chrome, Edge or Opera for the web apps (Web MIDI with SysEx).
  • The ES-8 on its play screen while editing: on the Bulk Dump screen it ignores what it receives.
